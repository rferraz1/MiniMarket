# MiniMarket
No projeto da mini loja virtual, as tecnologias utilizadas são:
	•	HTML: estrutura a página, definindo os elementos como títulos, botões, imagens e listas de produtos, formando o esqueleto do site.
	•	CSS: estiliza a página, controlando cores, fontes, espaçamentos, layout responsivo e efeitos visuais para tornar a loja atraente e fácil de usar em diferentes dispositivos.
	•	JavaScript: adiciona interatividade, permitindo listar produtos dinamicamente, adicionar itens ao carrinho, atualizar a quantidade de produtos, calcular o total da compra e controlar a abertura e fechamento do modal do carrinho.
